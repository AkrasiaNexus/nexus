# Generic internet slang (baseline)

A population-level list of common chat abbreviations and dropped apostrophes, the kind of dictionary a general-purpose normalizer ships with. Used as a baseline against personal profiles. It deliberately leaves out ambiguous forms such as "its", "ill" and "wont", which a generic tool can't resolve without knowing the writer.

# Idiolect profile (v0)

Paste this whole file into any model's system prompt. The tables are also read by the `idiolect` library.
v0 was hand-built from one session and first committed in cc9f7dc (`intent/intent.md`); the tables below hold exactly the entries v0 named.

## How to read me
- I type fast and casual: lowercase, little punctuation, frequent typos. Infer meaning; never ask me to fix spelling.
- Messages are often one run-on thought. Pull out the actual ask, then act.
- If I describe a frustration, I usually want it solved, not sympathized with.
