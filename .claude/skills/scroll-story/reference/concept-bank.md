# Concept bank: worked starting points (adapt, never copy)

Each entry: **thesis · signature · signature moment · arc beats · mobile note.** Swap in the real product's names, data and brand.

1. **Mobile app (any)**: "The app is the place it happens." · CSS-3D phone · the phone *performs* the core action physically (turns to scan, tilts to pour, flips to pay) · rise from dark → wake → home → hero action → proof (stats) → community → CTA · smaller phone, copy below. *(EcoSphere)*
2. **SaaS / dashboard**: "Chaos in, clarity out." · a single data line · scattered points on scroll condense into one clean chart, which becomes the product UI · noise → pattern → insight → action → team → CTA · reduce point count 4×.
3. **Fintech / budgeting**: "Every coin has a job." · coins as physical objects · coins fall and sort themselves into labelled jars as you scroll; one jar fills to a goal · spend chaos → sort → save → goal reached (climax) → CTA · coins become 2D tokens.
4. **Hardware / gadget**: "Engineered from the inside out." · exploded view · the product separates into layers along z, each layer a chapter, then snaps shut · reveal → explode → layer stories → reassemble (climax) → specs → buy · fewer layers, vertical explode.
5. **Food / drink brand**: "From field to glass." · the bottle/can · a liquid level rises with scroll while ingredients drift in and dissolve; the label draws itself · origin → ingredients → craft → pour (climax) → where to buy · keep the liquid as a CSS gradient.
6. **Education / course**: "Learning is doing." · an XP bar / map · scroll unlocks nodes on a path; each node is a lesson preview; the final node opens the signup · locked → first win → streak → mastery (climax) → enrol · path runs vertically.
7. **Event / conference**: "Countdown to the room." · a ticket · the ticket tears/flips through scroll: schedule printed on its back, speakers punched as holes, the stub becomes the CTA · invite → lineup → venue walk → tear (climax) → register · tickets stack.
8. **Agency / portfolio**: "We make things move." · kinetic type of the studio name · letters break apart and re-form into each project's title; projects reveal through the letterforms (mask) · name → work ×3 → method → contact · fewer letters, bigger.
9. **Nonprofit / cause**: "One person, then many." · a single dot (a person) · the dot multiplies into a crowd, then into a map of impact; one story is told in close-up first · one life → the problem → the response → collective (climax) → donate · dot counts capped.
10. **Real estate / venue / hotel**: "Walk in." · the floor plan · the 2D plan extrudes into rooms as you scroll; the camera walks a path through them · facade → enter → rooms → view (climax) → book · plan stays 2D with photos.
11. **Developer tool / API**: "Ship in one line." · a code line · a single line of code types itself, then expands into the architecture it replaces, then collapses back to one line · pain → one line → what it does → scale (climax) → docs CTA · reduce diagram nodes.
12. **Health / fitness**: "Small reps, big change." · a heartbeat/ring · a ring fills with each scroll 'rep'; at 100% it blooms into the body/goal visual · baseline → habit → streak → transformation (climax) → join · ring scaled, haptic-like tick sounds optional.

## How to remix
- **Swap the signature type** (object ↔ material ↔ verb ↔ place ↔ type) and see if it gets stronger.
- **Literalise the product's one verb** (scan, pay, ship, learn, book) as the climax.
- **Find the before/after state** in the product's promise and make the signature physically transform between them.
- **Kill test:** if the concept would work unchanged for a competitor, push it until it couldn't.
