# Portfolio

One page that links every project with its problem, its proof and a live demo. Static HTML with no build step, ready for GitHub Pages (`<username>.github.io`).

**Live preview:** https://claude.ai/artifact/F3d2TopkdsyACginYVcQ1E

When the projects move into their own repositories, update the "Source" links in `index.html`. Screenshots in `img/` are resized copies of each project's `docs/` images.
